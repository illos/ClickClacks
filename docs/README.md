## Development records

The other documents retain investigations, design decisions and release evidence.
They describe the revision and conditions named in each record. Historical
measurements, proposed work and old deployment details are not current setup
instructions. Evidence bundles referenced by local paths are maintained outside
Git and are not required to build or use the project.

The [version-one plan](v1-readiness-plan.md) and
[implementation record](v1-implementation.md) distinguish planned work from
changes that were implemented.

# ClickClacks v1.1.0

Version 1.1 exports the Customize dice panel's parts so an application can build its
own dice designer from them. It does not change dice results, graphics or the hosted UI.

## Install

```sh
pnpm add 'clickclacks@https://github.com/illos/ClickClacks/releases/download/v1.1.0/clickclacks-1.1.0.tgz'
```

Commit the resulting lockfile. Installation, the Three.js host patch and release
preparation are unchanged from [v1.0.0](v1.0.0.md).

## Customizer

`clickclacks/customizer` exports:

- `DiceDesignControls`: the Die color | Text color | Design segmented control with
  its color wheel, lightness slider and design tiles. `channels` adds a host's own
  segments before Design; each has a key, a label, an optional swatch color and the
  panel it opens.
- `DesignSwatches`: the pattern tiles, each a live preview in the die and text
  colors, and the font tiles rendering "01" in each font. `disabled` disables them.
- `ColorControls`, `DicePreview`, `paintDiePattern` (the procedural pattern shared by
  dice textures and tiles) and the font table (`dieFonts`, `dieFontFamilies`,
  `dieFontWeights`).

`clickclacks/customizer.css` styles these parts outside the roller's scoped theme.
Put `dice-customizer` on the element that holds the preview and the controls, and
set the `--customizer-*` colors listed at the top of the file to your theme; each
falls back to the roller's dark palette. Its selectors have the specificity of their
inner classes, so host rules override them. With four or more segments, a panel
narrower than 340px reads "Die" and "Text" beside their swatches.

The roller's own Customize dice dialog is unchanged: it keeps its scoped styles and
renders identically.

01 / SHARE YOUR TABLE

One table.
Two ways to join.

Every table has an eight-character code and a shareable link. Send either to your friends to bring everyone into the same dice tray.

  1. Open the people menu.Find your Table code and Table link.
  2. Copy and share.Send the link in chat, or read out the code at the table.
  3. Join and roll.Open the link to join directly. Or enter the code or link under Join a table in the people menu, then select Join.

03 / BUILD SOMETHING GOOD

Your project.
Our clacks.

Click Clacks is an open-source TypeScript dice framework. Use its dice engine, React components, and 3D presentation in your own project—or put the hosted roller in an iframe.

Share a table

Open the people menu to copy your table’s eight-character code or link, then send it to your group.

A link opens the table directly. To use a code, enter it under Join a table in the people menu and select Join. You’ll see everyone’s rolls in the same tray and history.

Use it in your project

Click Clacks is an open-source TypeScript framework, released under the MIT license. Use its dice engine and React components, or embed the roller with an iframe.

<iframe
  src="https://app.clickclacks.app/web/popout/tray.html"
  title="Click Clacks mini dice roller"
  width="100%"
  height="420"
></iframe>
import { generatePool } from 'clickclacks/dice';

const dice = generatePool([
  { sides: 20, count: 1 }
]);

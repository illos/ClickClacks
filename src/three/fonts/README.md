# Dice numeral fonts

Self-hosted digit-only WOFF2 subsets (0–9). Original SIL Open Font License files retained beside each asset.

Google Fonts source revision: 9710da1eacb3be272583c3224dcb70f9da6eadbb

Rune uses jagged, carved-looking Caesar Dressing numerals (Greek-inspired, not historical runes). Gothic uses New Rocker blackletter numerals. Both contain every Arabic digit 0–9; all remain numeric and readable. Glyphs were compared directly before choosing replacements.
